# patch-reach - SAM 3 environment. The cross-paradigm transfer arm only.
#
# One script runs here: scripts/sam3_transfer.py, which asks whether patches
# optimised against a Cityscapes-trained segmentor move a promptable,
# text-conditioned model that was never trained on Cityscapes at all.
#
# A THIRD ENV BECAUSE TWO WOULD NOT DO. SAM 3 wants a current torch (2.10 +
# cu128 here) and mmcv 1.x will not coexist with it - not "is awkward with",
# will not: mmcv-full 1.5.0 is a compiled extension built against torch 1.11's
# ABI. The script is written for that split and imports nothing from
# patchreach.models: only patchreach.patch (torch-only), patchreach.data and
# patchreach.metrics. Keep it that way.
#
# THE PATCH CROSSES THE ENV BOUNDARY AS PIXELS, which is the only reason the
# transfer number means anything. Patch.apply composites in NORMALISED space,
# so sam3_transfer.py normalises the image with the SAME IMG_MEAN/IMG_STD the
# patch was trained under, patches, denormalises and clamps, then hands SAM 3 a
# PIL image. The pixel patch SAM 3 sees is bit-identical to the one the mmseg
# eval saw. Do not "simplify" this by normalising with SAM 3's own statistics.
#
#   conda env create -f envs/sam3.yml
#   conda activate sam3
#   pip install -r envs/requirements-sam3.txt
#   git clone https://github.com/facebookresearch/sam3.git   # repo root
#   pip install -e sam3
#   pip install -e . --no-deps          # patchreach; --no-deps is required,
#                                       # see the note at the bottom
#
# WEIGHTS AND THE BPE VOCAB ARE NOT PIP PACKAGES. sam3_transfer.py takes both
# as paths (--sam3_ckpt, --sam3_bpe); the checkpoint can also be pulled with
# the clone's own `download_ckpt_from_hf`. The vocab ships inside the clone at
# sam3/sam3/assets/bpe_simple_vocab_16e6.txt.gz.
